## 建议执行顺序

1. **阶段一** → 先完成 C++ 核心库和 CGO 桥接，这是整个项目的性能基石
2. **阶段二** → 先做 2.1（调度框架）和 2.6（gRPC 通信），再做 2.3（限流）和 2.2（代理），最后 2.4（采集）和 2.5（续传）
3. **阶段三** → 先做 3.4（存储）和 3.1（gRPC），再做 3.2（节点）和 3.3（策略），最后 3.5（API）
4. **阶段四** → 全部完成后统一做集成测试和文档
