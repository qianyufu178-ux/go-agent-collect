## 一、流量治理模块（Nexus-Edge）

### 1.1 HTTP 反向代理

| 参数 | 默认值 | 可配置范围 | 说明 |
|------|--------|-----------|------|
| 监听端口 | `:80` | 1~65535 | 外部流量入口 |
| 上游业务端口 | `:9090` | 1~65535 | 本地受控业务端口 |
| 代理协议 | HTTP/1.1 | — | Go `ReverseProxy` 实现 |
| 上游连接超时 | 5s | 1s~60s | 连接后端超时 |
| 上游读取超时 | 10s | 1s~120s | 读取后端响应超时 |
| 上游写入超时 | 10s | 1s~120s | 写入后端请求超时 |
| 最大并发连接数 | 1024 | 1~65535 | 超出排队等待 |

### 1.2 限流策略

| 参数 | 默认值 | 可配置范围 | 说明 |
|------|--------|-----------|------|
| 全局 QPS 上限 | 1000 | 0~1000000 | 0 表示不限流 |
| 接口级 QPS | — | URL → QPS 映射 | 支持正则匹配路径 |
| 限流算法 | 令牌桶 | 令牌桶/滑动窗口/最大并发 | 支持切换 |
| 令牌桶速率 | 1000 r/s | 1~1000000 | 每秒填充令牌数 |
| 令牌桶容量 | 2000 | 1~1000000 | 最大突发量 |
| 滑动窗口大小 | 1s | 100ms~60s | 窗口时间跨度 |
| 滑动窗口上限 | 1000 | 1~1000000 | 窗口内最大请求数 |
| 最大并发数 | 500 | 1~65535 | 同时处理请求上限 |
| IP 白名单 | — | CIDR 列表 | 如 `192.168.1.0/24` |
| Header 白名单 | — | Key=Value 列表 | 如 `X-Internal-Service: true` |
| 降级状态码 | 429 | — | HTTP 429 Too Many Requests |
| 降级响应体 | `{"code":429,"msg":"系统繁忙，请稍后再试"}` | 自定义 JSON/文本 | Content-Type: application/json |
| 自适应 CPU 阈值 | 80% | 0~100 | 超过后限流阈值 ×0.5 |
| 自适应内存阈值 | 85% | 0~100 | 超过后限流阈值 ×0.5 |
| 自适应恢复判定 | 低于阈值 5% 持续 30s | — | 恢复原始限流阈值 |

## 二、观测采集模块（Nexus-Edge）

### 2.1 机器资源指标采集（C++ 解析 /proc）

| 指标 | 来源 | 单位 | 默认频率 | 可配置范围 | 说明 |
|------|------|------|---------|-----------|------|
| CPU 使用率 | `/proc/stat` | 百分比 (0.00~100.00) | 10s | 1s~300s | 系统总 CPU 占用 |
| 内存使用率 | `/proc/meminfo` | 百分比 (0.00~100.00) | 10s | 1s~300s | (总-可用)/总 ×100 |
| 磁盘 IO 读速率 | `/proc/diskstats` | KB/s | 10s | 1s~300s | 所有磁盘汇总 |
| 磁盘 IO 写速率 | `/proc/diskstats` | KB/s | 10s | 1s~300s | 所有磁盘汇总 |
| 网卡入带宽 | `/proc/net/dev` | KB/s | 10s | 1s~300s | 指定网卡或所有网卡汇总 |
| 网卡出带宽 | `/proc/net/dev` | KB/s | 10s | 1s~300s | 指定网卡或所有网卡汇总 |
| 磁盘使用率 | `/proc/mounts` + `statfs` | 百分比 (0.00~100.00) | 30s | 10s~300s | 指定挂载点 |

### 2.2 流量防护指标（Go 代理层实时统计）

| 指标 | 类型 | 说明 |
|------|------|------|
| total_requests | uint64 原子计数器 | 自启动累计总请求数 |
| blocked_requests | uint64 原子计数器 | 被限流/过载拦截的请求数 |
| current_qps | float64 滑动窗口 | 实时每秒请求数 |
| current_concurrency | int64 原子计数器 | 正在处理的请求数 |

### 2.3 业务日志采集（Go 文件监听）

| 参数 | 默认值 | 可配置范围 | 说明 |
|------|--------|-----------|------|
| 监听路径列表 | — | 多个文件路径 | 如 `/var/log/nginx/access.log` |
| 读取模式 | 增量读取 | — | 类似 `tail -f`，支持文件轮转 |
| 过滤模式 | 包含 | 包含/排除 | 关键词匹配模式 |
| 过滤关键词 | — | 字符串列表 | 如 `["ERROR", "FATAL"]` |
| 单条日志大小上限 | 10KB | 1KB~1MB | 超过截断 |
| 读取轮询间隔 | 1s | 100ms~60s | 检查文件新内容的间隔 |

## 三、弱网断点续传模块（Nexus-Edge）

### 3.1 断网判定

| 参数 | 默认值 | 可配置范围 | 说明 |
|------|--------|-----------|------|
| 判定条件 | gRPC 连续失败 | — | 心跳或数据上报失败 |
| 连续失败阈值 | 3 次 | 1~10 次 | 超过则判定为断网 |
| 心跳间隔 | 5s | 1s~60s | 与中控的心跳频率 |
| 数据上报超时 | 10s | 1s~60s | gRPC 流式上报超时 |

### 3.2 本地缓存

| 参数 | 默认值 | 可配置范围 | 说明 |
|------|--------|-----------|------|
| 存储方式 | SQLite | SQLite / 结构化文本 | `cache.db` 文件 |
| 缓存上限 | 100MB | 10MB~2GB | 超过后触发 FIFO 淘汰 |
| 淘汰策略 | FIFO | — | 先进先出覆盖旧数据 |
| 单条数据格式 | — | — | `时间戳|数据类型(metric/log)|JSON内容\n` |

### 3.3 恢复续传

| 参数 | 默认值 | 可配置范围 | 说明 |
|------|--------|-----------|------|
| 补发速率 | 50 条/s | 10~1000 条/s | 中控可下发背压控制 |
| 补发顺序 | 时间戳升序 | — | 先产生的数据先补发 |
| 补发完成后动作 | 清空本地缓存 | — | 删除已补发数据 |
| 重连检测间隔 | 3s | 1s~30s | 断网后尝试重连的频率 |

## 四、核心调度模块（Nexus-Edge）

### 4.1 配置管理

| 参数 | 说明 |
|------|------|
| 静态配置文件 | `nexus-edge.yaml`（YAML 格式） |
| 配置热更新 | 中控 gRPC 推送，本地生效无需重启 |
| 配置优先级 | 远端配置 > 本地文件配置 > 代码默认值 |

### 4.2 模块生命周期

| 模块 | 默认状态 | 说明 |
|------|---------|------|
| 流量治理模块 | 启用 | HTTP 代理 + 限流 |
| 观测采集模块 | 启用 | 指标采集 + 日志采集 |
| 断点续传模块 | 启用 | 本地缓存 + 恢复续传 |
| 模块启停方式 | 配置文件 / 中控下发 | 独立启停，故障隔离 |

### 4.3 本地管理接口（HTTP）

| 接口 | 方法 | 说明 |
|------|------|------|
| `GET /health` | — | 健康检查，返回 `{"status":"ok"}` |
| `GET /status` | — | 模块运行状态、QPS、连接数等详细状态 |
| `GET /metrics` | — | 当前采集的指标快照（Prometheus 格式兼容） |
| `GET /config` | — | 查看当前生效配置 |
| `POST /config/reload` | — | 触发本地配置文件重载 |

## 五、Nexus-Controller 中控端

### 5.1 节点管理

| 参数 | 默认值 | 可配置范围 | 说明 |
|------|--------|-----------|------|
| gRPC 监听端口 | `:9999` | 1~65535 | 边缘端接入端口 |
| 心跳超时判定 | 15s | 5s~120s | 连续未收到心跳 → Offline |
| 心跳检测间隔 | 5s | 1s~30s | 中控检查节点状态频率 |
| 节点注册方式 | 自动注册 | — | 首次连接自动分配 NodeID |
| 节点鉴权 | 可选 | 启用/禁用 | 预共享 Token 验证 |
| 节点信息记录 | — | — | NodeID、IP、版本、在线时长、策略版本 |

### 5.2 限流策略管理

| 参数 | 默认值 | 可配置范围 | 说明 |
|------|--------|-----------|------|
| 策略版本号 | 自增 ID | — | 每次修改递增 |
| 推送方式 | 长连接 PUSH | — | 通过 gRPC 双向流推送 |
| 推送回执 | Ack | — | 边缘端返回成功/失败 |
| 同步状态 | 已同步/待同步/失败 | — | 中控记录每个节点的策略状态 |
| 生效方式 | 立即热更新 | — | 边缘端收到后无需重启 |

### 5.3 数据存储（SQLite）

| 参数 | 默认值 | 可配置范围 | 说明 |
|------|--------|-----------|------|
| 数据库文件 | `nexus_center.db` | 自定义路径 | SQLite 文件 |
| 存储模式 | WAL | — | 防锁死，提高并发 |
| 写入方式 | Channel + 批量 | — | 避免直接写入阻塞 gRPC |
| 批量写入间隔 | 1s | 100ms~10s | 后台协程 flush 频率 |
| 批量写入大小 | 100 条/批 | 10~1000 | `CreateInBatches` |

#### 5.3.1 数据保留策略

| 数据类型 | 默认保留 | 可配置范围 | 清理策略 |
|---------|---------|-----------|---------|
| 节点性能指标 | 7 天 | 1~90 天 | 定时清理过期数据 |
| 业务日志 | 30 天 | 7~365 天 | 定时清理过期数据 |
| 限流统计 | 7 天 | 1~90 天 | 定时清理过期数据 |
| 节点注册信息 | 永久 | — | 手动删除 |
| 限流策略历史 | 永久 | — | 手动删除 |

> **清理机制**：后台定时协程，默认每天凌晨 02:00 执行，可配置清理时间。

### 5.4 HTTP 查询 API

| 接口 | 方法 | 说明 | 参数 |
|------|------|------|------|
| `GET /api/nodes` | 查询 | 所有节点状态列表 | — |
| `GET /api/nodes/:id` | 查询 | 单个节点详情 | — |
| `GET /api/metrics` | 查询 | 指标趋势数据 | `node_id`, `type`(cpu/mem/disk/net), `start`, `end` |
| `GET /api/logs` | 查询 | 业务日志检索 | `node_id`, `keyword`, `start`, `end`, `page`, `page_size` |
| `GET /api/strategies` | 查询 | 限流策略列表 | — |
| `POST /api/strategies` | 创建 | 创建/更新限流策略 | JSON body |
| `DELETE /api/strategies/:id` | 删除 | 删除限流策略 | — |
| `POST /api/strategies/push` | 推送 | 推送策略到节点 | `strategy_id`, `node_ids[]` |

## 六、非功能性需求

### 6.1 性能指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 限流判断 P99 延迟 | < 100μs | C++ 实现，无 GC 干扰 |
| 代理转发 P99 延迟 | < 5ms | 含上游业务处理时间 |
| Edge 常驻内存 | < 30MB | 空闲状态 |
| Edge CPU 占用 | < 5% | 空闲状态 |
| 数据上报吞吐 | ≥ 1000 条/s/节点 | gRPC 流式推送 |
| 中控并发节点数 | ≥ 1000 | 单机承载 |

### 6.2 工程约束

| 项目 | 要求 |
|------|------|
| 编译方式 | 单二进制，无外部运行时依赖 |
| 支持架构 | Linux amd64 + Linux arm64 |
| Go 版本 | 1.21+ |
| C++ 标准 | C++17 |
| 通信协议 | gRPC（双向流）、HTTP（管理接口） |
| 日志分级 | DEBUG / INFO / WARN / ERROR / FATAL |
| 错误码 | 统一错误码体系，便于排查 |

## 七、硬性约束（安全红线）

| 禁止项 | 说明 |
|--------|------|
| ❌ 进程扫描 | 禁止遍历/检测系统进程列表 |
| ❌ 端口探测 | 禁止扫描端口开放状态 |
| ❌ 网络抓包 | 禁止 pcap 等流量捕获能力 |
| ❌ 行为审计 | 禁止用户行为分析与审计 |
| ❌ 入侵检测 | 禁止任何安全告警/入侵检测逻辑 |
| ❌ 主机安全 | 禁止合规审计相关功能 |
| ❌ 漏洞扫描 | 禁止服务漏洞检测 |

> **仅保留**：基础机器资源指标采集、普通业务日志转发、流量限流治理 纯运维与流量防护能力。

## 八、数据模型定义

### 8.1 Edge 本地缓存数据格式

```
时间戳|数据类型|JSON内容\n
```

示例：
```
2026-07-28T08:00:00Z|metric|{"cpu":45.2,"mem":62.1}
2026-07-28T08:00:01Z|log|{"file":"/var/log/app.log","content":"ERROR: connection timeout","line":1024}
```

### 8.2 Controller SQLite 表结构

#### nodes（节点注册表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| node_id | TEXT UNIQUE | 节点唯一标识 |
| node_name | TEXT | 节点名称 |
| ip_address | TEXT | 节点 IP |
| version | TEXT | 软件版本 |
| status | TEXT | online/offline |
| strategy_version | INTEGER | 当前策略版本 |
| last_heartbeat | DATETIME | 最后心跳时间 |
| online_duration | INTEGER | 累计在线时长（秒） |
| created_at | DATETIME | 注册时间 |
| updated_at | DATETIME | 更新时间 |

#### metrics（性能指标表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| node_id | TEXT | 节点标识 |
| cpu_usage | REAL | CPU 使用率 |
| mem_usage | REAL | 内存使用率 |
| disk_read_kbps | REAL | 磁盘读速率 |
| disk_write_kbps | REAL | 磁盘写速率 |
| net_in_kbps | REAL | 网卡入带宽 |
| net_out_kbps | REAL | 网卡出带宽 |
| disk_usage | REAL | 磁盘使用率 |
| total_requests | INTEGER | 总请求数 |
| blocked_requests | INTEGER | 拦截请求数 |
| current_qps | REAL | 当前 QPS |
| collected_at | DATETIME | 采集时间 |

#### logs（业务日志归档表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| node_id | TEXT | 节点标识 |
| file_path | TEXT | 日志文件路径 |
| content | TEXT | 日志内容 |
| line_number | INTEGER | 行号 |
| collected_at | DATETIME | 采集时间 |

#### strategies（限流策略表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| name | TEXT | 策略名称 |
| version | INTEGER | 策略版本号 |
| global_max_qps | INTEGER | 全局 QPS 上限 |
| url_rules | TEXT(JSON) | 接口级限流规则 |
| ip_whitelist | TEXT(JSON) | IP 白名单列表 |
| header_whitelist | TEXT(JSON) | Header 白名单列表 |
| overload_cpu_threshold | REAL | CPU 过载阈值 |
| overload_mem_threshold | REAL | 内存过载阈值 |
| enabled | INTEGER | 是否启用 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

#### node_strategies（节点策略关联表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| node_id | TEXT | 节点标识 |
| strategy_id | INTEGER | 策略 ID |
| sync_status | TEXT | synced/pending/failed |
| pushed_at | DATETIME | 推送时间 |
| acked_at | DATETIME | 回执时间 |
